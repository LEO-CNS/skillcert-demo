# 技能申 · 上海市职业技能比照认定平台（Demo）

> 纯静态原型演示，全部样式与逻辑已内联在 `index.html`，双击即可打开。

## 在线地址
https://leo-cns.github.io/skillcert-demo/

## 三个角色
- **上海外服**：目录维护、证书核验、审批工作台（待办/已办/跟踪/退回）、导出 Excel 同步人社
- **C 端个人**：我的证书（本地保存）、免试资格查询、提交申请、查看进度
- **市人社局**：认定通过查询（只读 + 标记已读）
